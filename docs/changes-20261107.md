# 2026-11-07 本地开发版

版本：`local-operations.20261107`。未提交、推送或发布。

## 新增

- `check`：启动前检查多核心选择、节点身份、监听 IP、证书及 sing-box 配置字段格式。
- `configure` / `V2bX generate`：统一 Go 向导，每个节点独立核心，按节点选择住宅 SOCKS 或直连。
- `doctor`：本地配置、证书和监听检查；显式 `--network` 开启面板、DNS、SOCKS CONNECT 探测。
- `migrate-sing`：预览常见旧 DNS、domain_strategy、block 配置的迁移；`--write` 校验并备份后写入。
- 事务式安装、SHA256 校验、启动失败回滚及 `V2bX rollback`。

## 修复与升级

- sing-box 从 1.13.13 升级为 1.14.4，使用公开生命周期 scope 管理动态节点及资源释放。
- 不同域名证书分目录；校验证书私钥/SAN/有效期，修复自签证书与自动续期任务重试。
- sing-box 用户同步加锁、去重；不必要的更新不重建入站，失败更新尝试恢复旧用户。
- 配置向导正确生成 JSON 转义，密钥不回显，配置与备份文件权限 0600，写入失败回退已修改文件。
- 配套脚本直接从同一个包安装，消除 master 管理脚本与已装二进制版本不一致。
- 移除管理菜单中清空防火墙和关闭 SELinux 的行为，只对指定端口添加允许规则。
- 本地和 GitHub 构建覆盖三种 Linux 架构，并提供 `.zip.sha256`。

## 兼容边界

- 旧 Release 无 SHA256 时新安装器会拒绝安装。旧配置有已删除字段时先迁移，不能直接覆盖升级。
- 回滚二进制不回滚配置；降级前需恢复对应配置备份。
- 住宅向导默认仅 SOCKS TCP，无直连回退；供应商 UDP 和公网链路需另测。
- 真实用户变化仍重建动态入站，不是无断连热更新。
- 复杂配置迁移、完整配置重载的运行期失败回退、VPS 的 Xboard/流量/ACME 验收仍待完成。
- 独立 Hysteria 和 Xray 保持原版本，不声称已经升级到各自最新版。
