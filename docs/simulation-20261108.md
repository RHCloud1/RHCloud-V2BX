# 2026-11-08 模拟验收

本轮选择先模拟测试，再修复验证发现的问题。所有操作仅在本地副本进行，没有提交、推送或操作真实 VPS。
构建版本：`local-simulation.20261108`，内核版本保持 sing-box 1.14.4 / Hysteria 2.9.2 / Xray 1.251208.0。

## 环境与边界

- Windows 上的 Go 1.25.11 交叉编译，使用现有 WSL Ubuntu-22.04 执行 Linux 测试。
- Xboard 使用本机 HTTP 接口替身，住宅网关使用真实 sing-box SOCKS 入站，目标网站是本机 HTTP 服务。
- 服务端使用真实独立 Hysteria2 核心和 sing-box AnyTLS 核心，客户端也进行真实协议握手和数据转发。
- 测试只连接 IPv4/IPv6 回环地址；TLS 使用临时测试证书并显式信任该证书，没有关闭证书校验。
- 不安装新的系统软件，不使用真实面板 API Key、住宅账号、GitHub token 或生产证书。

这不是把完整 Xboard 应用安装进容器，也不代表已完成公网 VPS 验收。本轮真实协议通信只覆盖 HY2 与 AnyTLS，不代表其他全部协议均已端到端验收。
当前 WSL 没有 GCC，未运行 Go race detector；使用并发计数压力测试和重复端到端测试补充验证，不宣称等价于 race 检查。

## 覆盖项目

| 项目 | 验证方式 |
| --- | --- |
| 双协议 + 双核心 | HY2 独立核心直连；sing-box AnyTLS 经 SOCKS 网关转发 HTTP POST 和响应 |
| IPv4 / IPv6 | 分别监听 127.0.0.1 和 ::1；IPv6 入站可经 IPv4 网关出站 |
| TLS 与鉴权 | 正确凭据通过；错误密码、错误 SNI 必须失败 |
| 用户同步 | 面板 ETag / 304；显式空列表撤销最后一个用户；添加新用户；旧密码不再可用 |
| 流量回报 | 检查两个节点均产生上行、下行；模拟 503，缓存未确认流量并重试 |
| 住宅故障 | 停止 SOCKS 网关后 AnyTLS 请求失败，不转直连；HY2 仍可用 |
| 节点端口更新 | 新端口被占用时恢复旧节点；释放端口后下一次同步重试新配置 |
| 周期任务 | pull/push 分别更新；回调可安全修改间隔；关闭时等待正在执行的回调 |
| 启动失败清理 | 第二个节点绑定非本机 IP，或原生 HY2 配置文件不存在时，清理已启动的节点和任务 |
| 重启 | 完整关闭节点和核心后重新创建，重新同步面板并连接 HY2 |
| 并发计数 | 24 个写入者与并发 drain，检查总字节数没有因清零而丢失 |
| 安装器 | 继续执行坏校验、启动失败回滚、成功升级和手动回滚测试 |

测试会主动制造 `bad certificate`、认证失败、`HTTP 503`、`address already in use`、SOCKS 拒绝等日志；这些分支通过的条件就是请求被拒绝或旧节点恢复，不能只凭 ERROR 字样认定测试失败。

## 已修复

- 空列表和 304 明确区分，空列表不再被跳过；无用户时 sing-box 动态监听关闭，新增用户后恢复。
- 设备限制按用户独立计算，同步比较也包含 UID、速率和设备数。
- 面板失败响应不进入节点缓存；缺少可选 base_config 时使用安全间隔，坏路由不再直接 panic。
- API 错误和重试日志避免暴露 token，在线报告不再吞掉错误。
- 流量计数初始化加锁、清零使用原子交换；未确认的上报保留在内存中重试。
- 控制器同步、上报和动态限速串行执行；定时任务不再持有自身调度锁运行回调。
- 单节点面板更新失败时尝试恢复旧配置，并使面板缓存失效以允许重试。
- 部分启动失败和正常关闭时清理已启动节点；原生 HY2 配置读取失败返回错误，不直接终止整个进程。
- 限制器的共享规则、在线映射和速率状态补充同步保护；无效正则返回错误且保留旧规则。

流量重试仍不是严格 exactly-once：如果面板收到并计费但响应丢失，重试可能重复计费；内存队列也不耐进程崩溃或重启。该问题需要面板侧幂等支持及持久化队列配合，不能靠本次测试证明解决。

## 复现

在仓库根目录运行：

```powershell
./script/test-linux.ps1
./script/test-linux.ps1 -Packages ./node -Repeat 10 -Run TestSimulatedXboardNativeHY2AndResidentialAnyTLS
./script/build.ps1 -Architectures amd64,arm64,s390x
```

新包位于 `dist/local-simulation.20261108/`，旧包保留。上传 ZIP 时也需要同名 `.zip.sha256`。
安装方法见 `local-build.md`；回退行为和配置迁移见 `operations.md`。
