# 2026-11-17 补齐 wyx2685 上游维护

wyx2685/V2bX 已于 2025-12 停止维护并归档（最后版本 v0.4.0 / 提交 71277de）。
本仓库的代码来自不同时期的上游：`core/xray` 约为 2024-07，其余大多为 2025-01（2f13620）。
本次按文件三方合并（基准为本仓库首个版本最接近的上游版本），把上游到 71277de 为止的修复与功能补齐，
冲突处保留本仓库已有的改进。不再合并上游 Git 历史。

## 新增

- TUIC 节点（sing 核心）：面板 `tuic` 类型、`congestion_control`、`zero_rtt_handshake`；必须配置证书；向导选项 `9.TUIC`。
- VLESS Encryption（xray 核心）：读取面板 `encryption` / `encryption_settings`；Reality 支持 `mldsa65Seed`。
- xray 核心支持 `httpupgrade`、`xhttp`（`splithttp`）传输。
- 用户列表优先请求 msgpack（`X-Response-Format: msgpack`），面板不支持时回退 JSON。
- `ApiSendIP`：访问面板 API 时绑定指定本机源 IP。
- `ReportMinTraffic`（KB）：单个用户本周期流量不超过该值时暂存，累计超过后再上报；0 为不限制。
  注意上游示例写成了 `MinReportTraffic`，实际读取的字段名是 `ReportMinTraffic`。
- Hysteria2：读取面板 `ignore_client_bandwidth`（sing 与独立 hy2 核心）；独立 hy2 核心支持 `sniff` 配置。

## 修复

- 设备数限制：上一上报周期已在线的 IP，在新周期重连时不再被误拒（上游 fc284b3）。
- 删除用户、修改限速时同步清除旧的限速桶，新限速立即生效（上游 8d225f8）。
- xray 删除用户时主动断开该用户的现有连接；修复重复加锁卡死、开启 splice 后限速失效、自有连接空指针、mux panic。
- xray 流量统计改为 V2bX 自有计数器，支持 splice；`shouldOverride` 前缀判断恢复为 Xray 原逻辑。
- 删除用户时清除其流量计数器，避免长期运行内存增长。
- 速率限制在读写完成后按实际字节数等待（上游 #120）。
- 去掉用户列表 `alive_ip` 的本地设备数扣减：在线设备只按 `alivelist` 统计，避免两处同时扣减导致误拒。
- 退出信号不再注册无法捕获的 SIGKILL。

## 删除

- `LimitConfig` 中的本地 `ConnLimit`、`DeviceLimit`（IPLimit）、`EnableRealtime` 不再生效（上游同样移除了实现）。
  设备数请在面板为用户设置。字段仍可解析，旧配置无需修改即可启动。

## 未采纳的上游改动

- 上游 2025-12 的 `common/task` 重写：本仓库已用 `execution` 锁和 `SetInterval` 修复同一个 pull_interval 死锁，并有回归测试。
- 上游 `GetUserTrafficSlice`：读后清零会丢失并发流量，且动态限速不再累计流量；本仓库保留原子 `Take` 与失败重试，阈值在控制器实现。
- 上游 sing 内核 `AddUsers`/`DelUsers` 依赖其私有 sing-box 分支（sing-box_mod）；本仓库使用官方 sing-box 1.14.4，用户变化仍重建入站。
- 上游节点重载失败时 `Panic`：本仓库保留失败回退。
- 上游日志改为直接追加文件：本仓库保留 lumberjack 轮转。
- 上游 `GOEXPERIMENT=jsonv2`：本仓库继续使用 goccy/go-json，无需实验特性。

## 验证边界

- 本地与 CI 运行单元测试和编译；新增 TUIC、VLESS Encryption、xhttp 未在 VPS 上实测，发布前需要实机验证。
