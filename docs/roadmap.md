## 第一阶段：多节点部署稳定性

- [x] 证书隔离：配置向导按域名生成路径；同域名可以共用，不同域名不能误用同一份证书。
- [x] 证书校验：检查私钥匹配、有效期及 SAN，发现错误时给出具体说明；修复自签证书生成。
- [x] 配置向导：修复先后选择不同核心时的协议菜单，允许选择 IPv4/IPv6 监听；HY2/AnyTLS 强制配置证书。
- [x] 启动前检查：提供 `V2bX check`，检查核心选择、节点重复、证书和监听地址；启动服务前执行同样检查。
- [x] 用户同步：并发访问加锁，避免空更新和重复用户导致不必要的入站重建；失败时尝试恢复原有用户配置。
- [x] 回归验证：离线测试，检查脚本语法，提供 HY2 + AnyTLS 及独立住宅出口示例。
- [x] 本地构建：生成 Linux amd64 / arm64 包及 SHA256 校验值，保持安装器要求的文件名。

2026-11-07 验证：8 个有测试的 Go 包均在 WSL Linux 下运行通过；两份配置向导的多核心/TLS/监听回归测试通过；3 个部署 Shell 脚本语法检查通过。
实际 Linux 二进制通过双节点示例配置检查；缺失配置返回退出码 1。产物为 `dist/local-multinode.20261107/`。
以上为第一阶段记录；Windows 原生全量编译曾受旧版 sing-box/sing-tun 的接口不匹配影响。本轮交付目标为 Linux，不承诺原生 Windows 服务端支持。

## 验收边界

通过本地测试和构建不等于通过 VPS 实机验收。编译内核版本、构建结果和待实机验证项要在交付时单独列明。
`check` 只做本地检查，不联系 Xboard、不申请证书、不验证公网防火墙；实际端口由 Xboard 下发，运行时绑定仍可能失败。
